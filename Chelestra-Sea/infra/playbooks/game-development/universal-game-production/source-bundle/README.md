# Universal Harness Source Bundle

This directory is the GitHub-friendly archival form of the complete Universal AI Game Production Harness v1.

The source was concatenated in deterministic path order and split into numbered chunks only to fit repository/API transport limits.

## Reconstruct

Concatenate in numeric order:

`part-01.md` through `part-06.md`

The resulting text contains every extracted source file, each preceded by:
- original relative path;
- SHA-256 hash;
- fenced original contents.

For normal use, start with the parent `START_HERE.md` and `PLAYBOOK.md`. The source bundle is primarily for complete archival/reconstruction and for LLMs that need to recover the full reusable harness without the original ZIP.
