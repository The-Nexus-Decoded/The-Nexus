# Universal AI Game Production Playbook

Use this package for any game genre or platform. It provides the reusable multi-LLM production core, project profiles, genre/platform modules, asset pipelines, testing, networking, releases, and independent verification.

Contents:

- `PLAYBOOK.md` — readable playbook
- `START_HERE.md` — entry point
- `DELIVERY_NOTES.md` — email/delivery summary
- `SOURCE_BUNDLE.part-*.md` — complete extracted harness source in GitHub-friendly chunks

This folder must not acquire SoulDrifter-specific lore or gameplay assumptions.
